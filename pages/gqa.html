Scene Graphs for Visual Question Answering

Generating structured relationships between objects to improve visual question answering when scene graph annotations are missing.

11%GraphVQA accuracy improvement on scene graph-deficient test sets

This multimodal machine learning class project explored how scene graphs—structured representations of objects and their relationships—can support visual question answering (VQA).

My contribution

I designed a scene graph generation pipeline using MotifNet and bottom-up attention networks, then fine-tuned GraphVQA with generated scene graphs. This improved accuracy by 11% on scene graph-deficient test sets.

Research directions

  • Fine-grained reasoning: use object-level and relationship information alongside global visual features to help answer questions about a scene.
  • Pre-training: explore masking relationships and object features so models learn to recover missing contextual information.
  • Low-resource datasets: investigate scene graph features for prompt initialization and generate scene graphs where annotations are unavailable.
