CenterPoint Joint Object–Attribute Prediction

Extending a LiDAR-based 3D detector to jointly predict objects and attributes, including vehicle type and pedestrian posture.

83%average precision for vehicle and pedestrian object–attribute pairs

This project extended the CenterPoint 3D detection model to predict object attributes alongside detections in autonomous driving LiDAR data.

My contribution

  • Led the design and implementation of joint object and attribute prediction.
  • Managed data processing and augmented the nuScenes dataset with attribute labels.
  • Fine-tuned the model on both detection and attribute prediction objectives.

Results

The model achieved 83% average precision for vehicle and pedestrian object–attribute pairs.
